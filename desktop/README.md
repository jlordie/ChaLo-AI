# ChaLo AI - Desktop Application

Electron-based desktop application for ChaLo AI on Windows, macOS, and Linux.

## Getting Started

```bash
cd desktop
npm install
npm run dev
```

## Build Distribution Packages

```bash
npm run package
```

Outputs:
- Windows: `.exe` and `.msi`
- macOS: `.dmg`
- Linux: `.AppImage` and `.deb`
